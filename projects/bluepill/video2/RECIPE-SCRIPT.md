## 3. Where we deliberately differ
- UF cites nobody; we cite by chip and one phrase, because the series promise is accuracy and sources (PLAN.md).
- UF narrator never hedges; we hedge but compress hedges into short verdict lines.
- UF stays in the myth; ours turns the myth into a case file at about 4:00, so the second half is a line-up of suspects, each told as a scene.
