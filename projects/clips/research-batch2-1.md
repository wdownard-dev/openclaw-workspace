## Method and limits (read first)
- No browser could be started on this host (the browser tool reports no Chrome/Chromium). Twitch About text and panels were read instead from Twitch's public web data endpoint (the one the Twitch site itself uses), which returns the channel bio, social links and **panel text/links**. **Image-only panels carry no readable text**, so a policy shown only inside a panel image is **unverified** for every streamer below.
- X bios and the Cloudflare-obfuscated emails in them were decoded from the public X page. YouTube channel descriptions/About were read from the public page HTML. Linktree/carrd pages were read where they loaded.
- Not readable: Discord rules/channels, chat commands (`!clips` etc.), Throne, summit1g.gg (fetch blocked), scaredcomfy.com (binary response).
- Web searches (Oct 2026) found **no streamer-specific clip policy statement for any of the 8**.
- No policy was found for ANY of the 8, so all 8 stay `candidate` until a written yes.
- Platform note that applies to everyone: YouTube announced on 2026-10-01 that Shorts recommendations will favor original content and reduce reach for channels that mostly reupload others' clips; per coverage, the reused-content monetization rule applies **even with the creator's permission**. Plan on real commentary/editing.
