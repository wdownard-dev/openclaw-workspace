Morpheus Clips - Privacy Policy

Last updated: October 22, 2026

Morpheus Clips is a private tool operated by one individual creator ("I"). It is used only with my own Google account and my own YouTube channel.

YouTube API Services

Morpheus Clips uses YouTube API Services. By using it you are bound by the YouTube Terms of Service. Google's data practices are described in the Google Privacy Policy.

What access the app requests

  • Upload videos (youtube.upload): to upload approved videos to my own channel.
  • Read-only access (youtube.readonly): to read my own channel's upload status and basic performance.

What data is accessed and stored

The app accesses only data belonging to the authorizing account's own channel. It does not access the accounts or data of any other users or viewers. The only credential stored is an OAuth refresh token, kept in a protected local credential store with restricted file permissions on my own computer.

Sharing

I do not sell, rent, share or transfer data obtained through YouTube API Services to anyone. Data is used only to operate the upload and status features described above. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. When access is revoked, or on request, the stored token is deleted.

Contact

Questions or requests: open an issue at github.com/wdownard-dev/morpheus-clips/issues.
