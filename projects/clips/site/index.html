Morpheus Clips

Morpheus Clips is a small personal tool run by an individual creator. It prepares short vertical video clips (YouTube Shorts) of livestream highlights and uploads them to the creator's own YouTube channel.

How it works

  • Clips are only made from streamers who have given explicit permission.
  • Each clip gets original captions, a title and commentary added by the creator.
  • Every upload is reviewed and approved manually before it is published.
  • The tool uploads to the creator's own channel only and reads that channel's upload status and basic performance.

The tool is not a public service and has no user accounts. It runs privately on the creator's own computer.
